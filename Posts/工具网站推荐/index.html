工具网站推荐

发表于2026-10-02|更新于2026-10-03|资源分享
|浏览量:

这里整理一些平时比较实用的在线工具网站。尽量以无需安装、打开即用、功能明确为主，后续发现好用的网站会继续补充。

部分在线工具需要把文件上传到第三方服务器。涉及身份证、合同、证书、未公开资料等敏感文件时，建议优先使用本地软件处理。

图片编辑工具

Photopea

网站： https://www.photopea.com/

在线图片编辑器，界面和操作逻辑与 Photoshop 比较接近，适合临时处理 PSD、PNG、JPG、WebP 等图片。

常用功能：

  • 打开和编辑 PSD 文件
  • 图层、蒙版、选区、文字、滤镜
  • 图片裁剪、缩放和简单修图
  • 导出 PNG、JPG、WebP、SVG 等格式
  • 不想为了临时改一张图而安装大型软件时非常方便

适合： PSD 临时修改、网页素材处理、截图编辑、简单设计。

Squoosh

网站： https://squoosh.app/

非常适合做网页图片压缩和格式转换，可以直接对比压缩前后的画质与文件大小。

常用功能：

  • JPG、PNG、WebP、AVIF 等格式转换
  • 调整压缩质量
  • 修改图片尺寸
  • 实时对比压缩效果

适合： 博客图片、网页资源、封面图压缩。

TinyPNG

网站： https://tinypng.com/

操作很简单的图片压缩工具，拖入图片即可压缩。

适合： 快速减小 PNG、JPG、WebP 等图片的体积。

remove.bg

网站： https://www.remove.bg/

用于自动去除图片背景，适合人物、商品等主体比较明确的图片。

适合： 头像抠图、商品图、演示文稿素材制作。

SVGOMG

网站： https://jakearchibald.github.io/svgomg/

用于压缩和优化 SVG 文件，可以删除 SVG 中大量冗余信息。

适合： 网站图标、Logo、矢量资源优化。

PDF 工具

PDF24 Tools

网站： https://tools.pdf24.org/

提供较完整的 PDF 在线处理功能。

常用功能：

  • PDF 合并与拆分
  • PDF 压缩
  • 图片转 PDF
  • PDF 转图片
  • 页面旋转、删除和排序
  • 添加水印

适合： 日常学习资料和普通文档处理。

iLovePDF

网站： https://www.ilovepdf.com/

也是比较常见的一站式 PDF 工具网站，界面简单，适合快速处理 PDF。

适合： 合并、拆分、压缩、转换等常见操作。

文件格式转换

CloudConvert

网站： https://cloudconvert.com/

支持多种文件格式之间的转换，适合处理一些本地软件不方便直接转换的格式。

适合： 图片、音频、视频、文档等格式转换。

Convertio

网站： https://convertio.co/

在线文件格式转换工具，支持的格式类型比较丰富。

适合： 临时进行跨格式转换。

开发与文本工具

regex101

网站： https://regex101.com/

正则表达式测试和调试工具，可以实时查看匹配结果，并解释表达式的各个部分。

适合： 编写和调试正则表达式。

CyberChef

网站： https://gchq.github.io/CyberChef/

功能非常丰富的浏览器端数据处理工具，可以通过组合操作完成编码、解码、哈希、文本转换等任务。

适合：

  • Base64 编码/解码
  • URL 编码/解码
  • 哈希计算
  • 十六进制与文本转换
  • JSON、字符串及各种数据处理

JSON Formatter & Validator

网站： https://jsonformatter.curiousconcept.com/

用于格式化和检查 JSON 内容，在排查接口返回内容或配置文件格式问题时比较方便。

网络与查询工具

Speedtest

网站： https://www.speedtest.net/

用于测试网络下载速度、上传速度和延迟。

IPinfo

网站： https://ipinfo.io/

用于查询当前公网 IP 以及网络运营商、ASN 等基本网络信息。

使用建议

不同在线工具的实现方式不同，大致可以分为两类：

  1. 浏览器本地处理：文件主要在浏览器中完成处理，通常更适合隐私敏感一些的内容。
  2. 上传服务器处理：文件需要先上传到网站服务器，再返回处理结果。

对于普通图片、公开资料，在线工具非常方便；但涉及账号密码等敏感信息时，建议尽量使用可信的本地工具。
